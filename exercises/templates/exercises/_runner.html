{% comment %}The exercise runner, shared by one exercise's page and a session page. Every question is rendered server-side in full; exercise_runner.js reveals one at a time and submits the answer to ExerciseSubmitView, which grades it, records it for a signed-in learner and sends the verdict back. The correct answers are deliberately not in this page. With JavaScript off the page is a readable list of questions — the controls stay hidden instead of pretending to work. Two pages draw from this file: one exercise (exercises/exercise_detail.html) and a session that gathers questions from many exercises (exercises/session.html). The only things they disagree about are passed in — where "back" goes and what it says, an optional "next" link, and the two result headings — so the runner itself has exactly one definition and cannot drift between them. Each question carries its *own* submit and hint URL. A single-exercise page could put one URL on the runner, but a session's questions come from several exercises, and the server grades each answer against the exercise it really belongs to.{% endcomment %}
